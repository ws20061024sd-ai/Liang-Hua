## 一、项目概览

### 一句话描述

半自动化 A 股量化交易系统——每日自动分析沪深 300 成分股，生成买卖信号推送到钉钉，用户人工确认后在券商 APP 手动下单。附带纯静态仪表盘网站，通过博客域名 `xoln.me/quant` 访问。

### 关键数字

| 维度       | 数据                                                |
| ---------- | --------------------------------------------------- |
| 覆盖股票   | 319 只（沪深 300 成分股 + 动态调整）                |
| 历史数据   | 2019-01-01 至今，7+ 年日线                          |
| 运行策略   | 3 个并行（双均线 / 动量突破 / 均值回归）            |
| 每日信号   | 平均 10-25 条买入建议                               |
| 财务数据   | 319 只 × 7 年 = 51 万条 PE/PB/ROE                  |
| 仪表盘页面 | 8 个（首页/市场/历史/策略/因子/信号/健康/股票详情） |
| 测试覆盖   | 26 个单元测试                                       |
| 回测引擎   | 2 个（本地 + 聚宽云端）                             |

### 核心设计原则

```
数据下载 → 策略计算 → 三道防线过滤 → 信号汇总 → 钉钉推送
                                                ↓
                                         用户手机查看
                                                ↓
                                    人工判断 → 券商APP手动下单
```

**红线**：系统不自动交易，不连接券商 API，所有买卖由用户手动执行。

### 3.2 核心模块详细说明

#### `run.py` —— 主入口（363行）

```
职责：编排每日完整流程

流程：
  1. ensure_schema()           自动迁移数据库schema
  2. download_all()            AKShare下载日线（优先本地缓存成分股）
  3. fix_pct_change()          SQL补全涨跌幅NULL值
  4. download_all_financial()  Baostock下载PE/PB/PS/PCF
  5. fix_financial_data()      清洗PE/PB异常值
  6. verify_data_quality()     6项数据完整性检查
  7. data_check.py --block     阻断校验（不通过则不推信号）
  8. get_market_regime()       大盘四档状态判断
  9. run_strategies()          三策略并行 → 原始信号
  10. filter_signals()         基础风控过滤
  11. filter_by_regime()       大盘择时（降权，不拦截）
  12. aggregate()              多策略交叉确认
  13. save_signals()           持久化到DB
  14. send()                   钉钉推送

命令行参数：
  --no-update    跳过数据下载，直接生成信号
  --init         首次初始化（建库+下载7年历史数据）
  --verbose      显示详细日志
```

#### `data_fetcher/downloader.py` —— 日线下载器

```
数据源：新浪（主）→ 东方财富（备用）
策略：
  - 批量SQL：1次GROUP BY替代300次单查
  - 本地缓存：成分股列表从stock_info读，不每次调API
  - 前向回填：检测并修复历史数据缺失
  - 二轮重试：失败股票集中重试（1s间隔）
  - 串行执行：AKShare V8引擎不支持多线程
速度：~100秒/300只（增量模式通常<10秒）

核心函数：
  fetch_hs300_constituents()  获取成分股（优先缓存）
  download_stock_history()    单只股票下载（双数据源）
  fix_pct_change()            SQL反算涨跌幅
  verify_data_quality()       6项完整性检查
```

#### `engine/runner.py` —— 策略运行器

```
职责：批量加载数据 → 遍历股票 → 运行策略 → 收集信号

STRATEGY_REGISTRY 注册表：
  MaCrossStrategy       双均线
  MomentumBreakoutStrategy  动量突破
  MeanReversionStrategy   均值回归

核心函数：
  get_enabled_strategies()   根据配置创建策略实例

                             集成止损检查（position_tracker）
```

#### `engine/risk_filter.py` —— 基础风控

```
过滤规则（硬性拦截，不可跳过）：
  ✗ ST 股票（is_st=1）
  ✗ 涨停股（pct_change >= 9.9% 或接近涨停价）
  ✗ 跌停股（pct_change <= -9.9%）
  ✗ 停牌股（volume=0 或 pct_change=0）
  ✗ 新股（上市 < 60天）
  ✗ 股价超限（> MAX_STOCK_PRICE，买不起1手）
  ✗ 流动性差（日均成交额 < 2000万）

仓位计算（按本金自动分档）：
  1-2万   单票≤50%  止损-3%  最多2只
  2-5万   单票≤30%  止损-5%  最多4只
  5-10万  单票≤20%  止损-5%  最多6只
  10万+   单票≤15%  止损-5%  最多10只
```

#### `engine/market_timing.py` —— 大盘择时

```
四档状态判断（基于沪深300 vs MA20/MA60）：
  🟢 强势   指数>MA20 且 MA20>MA60      权重系数 1.0
  🟡 震荡   指数>MA20 但 MA20<MA60      权重系数 0.3
  🟠 弱势   指数<MA20                    权重系数 0.0
  🔴 极弱   指数<MA60 且连续10日下跌      权重系数 0.0

v0.3.0 变更：不再拦截买入信号
  - 弱势市：趋势策略×0.3，回归策略×0.5
  - 极弱市：趋势策略×0.1，回归策略×0.2
  - 信号保留但标注 "🔽降权" / "🔼增强"
```

#### `engine/signal_aggregator.py` —— 信号汇总

```
多策略交叉确认：
  ⭐⭐  双策略确认（2个策略同时建议买入同一只股票）
  ⭐    单策略信号
  ⚠️   策略冲突（一个说买一个说卖）

冲突检测规则：
  - 同一股票在同一天出现 BUY + SELL → 标记冲突
  - 冲突信号不丢弃，标注后展示给用户判断
```

## 四、数据库设计

### 4.1 完整表结构

```sql
-- 股票基本信息
stock_info (
    code        TEXT PRIMARY KEY,    -- 6位代码，如 '000001'
    name        TEXT,                -- 股票名称
    market      TEXT,                -- 市场（sh/sz/bj）
    listing_date TEXT,               -- 上市日期
    is_st       INTEGER DEFAULT 0    -- 是否ST
)

-- 日线行情（核心表，~70万条）
daily_kline (
    code        TEXT,                -- 股票代码
    date        TEXT,                -- 日期 YYYY-MM-DD
    open        REAL,                -- 开盘价（前复权）
    high        REAL,                -- 最高价
    low         REAL,                -- 最低价
    close       REAL,                -- 收盘价
    volume      REAL,                -- 成交量（股）
    amount      REAL,                -- 成交额（元）
    pct_change  REAL,                -- 涨跌幅（%）
    turnover    REAL,                -- 换手率（%）
    PRIMARY KEY (code, date)
)
CREATE INDEX idx_kline_code_date ON daily_kline(code, date)

-- 指数日线
index_daily (
    date  TEXT PRIMARY KEY,          -- 日期
    open  REAL, close REAL,          -- OHLC
    high  REAL, low REAL,
    volume REAL, amount REAL         -- 成交量和成交额
)

-- 财务估值数据（51万条）
financial_data (
    code         TEXT,               -- 股票代码
    date         TEXT,               -- 日期
    close        REAL,               -- 收盘价
    pe           REAL,               -- 市盈率(TTM)
    pb           REAL,               -- 市净率(MRQ)
    ps           REAL,               -- 市销率(TTM)
    pcf          REAL,               -- 市现率(NcfTTM)
    roe          REAL,               -- 净资产收益率
    roa          REAL,               -- 总资产收益率
    gross_margin REAL,               -- 毛利率
    net_margin   REAL,               -- 净利率
    revenue_yoy  REAL,               -- 营收同比
    profit_yoy   REAL,               -- 利润同比
    market_cap   REAL,               -- 总市值
    circ_mv      REAL,               -- 流通市值
    total_assets REAL,               -- 总资产
    PRIMARY KEY (code, date)
)

-- ROE 季度数据（19293条）
financial_roe (
    code TEXT, date TEXT, roe REAL,
    PRIMARY KEY (code, date)
)

-- 信号历史
signal_history (
    id       INTEGER PRIMARY KEY AUTOINCREMENT,
    date     TEXT,                   -- 信号日期
    code     TEXT,                   -- 股票代码
    name     TEXT,                   -- 股票名称
    strategy TEXT,                   -- 策略名称
    action   TEXT,                   -- BUY / SELL / STOP_LOSS
    strength REAL,                   -- 信号强度（0-1）
    price    REAL,                   -- 信号价格
    reason   TEXT,                   -- 信号原因
    status   TEXT,                   -- passed / blocked
    reject_reason TEXT               -- 拦截原因
)

-- 行业板块缓存
sector_history (
    date       TEXT,                 -- 日期
    name       TEXT,                 -- 行业名称
    pct_change REAL,                 -- 涨跌幅
    net_flow   REAL,                 -- 资金净流入
```

### 4.3 数据库自动迁移

`scripts/ensure_schema.py` 在每次 `run.py` 启动时自动运行：

```
原理：
  1. 定义 EXPECTED_SCHEMA（期望的表结构）
  2. PRAGMA table_info → 获取实际列
  3. 期望列 - 实际列 = 缺失列
  4. ALTER TABLE ADD COLUMN 自动补充

优点：
  - 零手工：加新列只需更新 EXPECTED_SCHEMA 字典
  - 幂等：重复运行无副作用
  - 启动耗时 < 10ms

局限性：
  - SQLite 不支持 ALTER TABLE DROP COLUMN
  - 不支持修改列类型
  - 对简单场景（加列）完美覆盖
```

### 6.3 止损机制


### 8.2 数据质量五层保障

```

  - 每只股票3次重试（退避0.3s/0.6s）

第三层：质量检查（6项）
  ① 数据日期 = 今天？

  ③ pct_change 无 NULL？
  ④ 涨跌幅极值 ≤ 5条？
```

### 12.2 策略迭代规范

```
1. 改参数 → 本地 run.py --no-update 观察信号
2. 跑回测 → python backtest/simple_backtest.py
3. 对比指标 → 夏普/回撤/胜率 改善？
4. 聚宽验证 → 如果是排名策略则必须
5. 确认无误 → git commit + push
6. 服务器 git pull
7. 观察几天信号质量
```

### 12.3 数据源接入标准流程

```
1. 单只股票验证（10行脚本，确认数据格式）
2. 10只股票验证（确认稳定性和速度）
3. 全量下载（319只，确认覆盖率 ≥ 85%）
4. 人工核对（随机抽5只 vs 同花顺官网）
5. PIT检查（财务数据需要滞后吗？）
6. 写入文档（数据源对比分析.md）
```

## 十四、技术债务与已知限制

| 项                         | 说明                                     |     优先级     |
| -------------------------- | ---------------------------------------- | :------------: |
| AKShare 不支持多线程       | V8引擎限制，日线下载串行 ~100s           |   低（够用）   |
| 本地回测 vs 聚宽偏差 6.5pp | 底层价格数据源不同，排名策略不可本地迭代 | 中（已文档化） |
| 板块数据依赖 report.py     | run.py 有兜底但 report.py 才是主入口     |       低       |
| SQLite 单文件              | 并发写入无冲突（WAL模式），但无法分布式  |  低（不需要）  |
| Baostock Pandas 3.x 兼容   | 需要 monkey-patch，等 Baostock 官方更新  |       低       |
| 交易日历需定期更新         | 目前用 AKShare 实时查询                  |       低       |
