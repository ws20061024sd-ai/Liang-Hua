
# 量化仪表盘——模块优化方案

> 2026-07-06 | 逐模块推进，优先修数据源，再改展示

---

## 优化原则

1. **每个字段都有决策参考价值**——无用信息一律去掉
2. **数据来源必须如实标注**——不禁用虚假标签
3. **先修数据源，再改展示**——数据不对，UI再好看也没用

---

## M1: 历史模块 ✅ 已完成（2026-07-11）

### 当前状态

web/output/history/ 下有 30 天快照 JSON，history.html 展示市场宽度和信号摘要。

### 核心问题

"均价 70" 毫无参考价值。没人需要知道 287 只股票的平均股价是 70 块还是 66 块。

### 优化

| 项           | 当前                   | 目标                                                               |
| ------------ | ---------------------- | ------------------------------------------------------------------ |
| 指数数据     | `AVG(close)` ≈ 70元 | AKShare 下载真实沪深300指数（`sh000300`），存 `index_daily` 表 |
| 5日/20日涨跌 | 均价变化               | 真实指数涨跌幅                                                     |
| 趋势判断     | MA20/MA60 基于均价     | 基于真实指数                                                       |
| 总成交额     | 无                     | `SUM(amount)` 按日聚合                                           |
| 历史对比     | 仅30天快照             | 含指数点位+成交额的趋势对比                                        |

### 实现步骤

1. `data_fetcher/` 新建 `index_downloader.py`：AKShare → `index_daily` 表
2. 回溯补全历史指数数据
3. `web/generate.py` `_market()` 改为查询 `index_daily` 表
4. 新增 `_turnover()` 函数：`SUM(amount) FROM daily_kline WHERE date=?`
5. index.html 市场条更新标注
6. market.html 更新指数显示
7. history.html 均价微走势图改为指数走势图

## M2: 信号首页

### 当前状态

geo-blobs hero + 数据审查 banner + 涨跌家数市场条 + 信号排名 + 拦截统计。

### 优化

| 项         | 当前                           | 目标                                                       |
| ---------- | ------------------------------ | ---------------------------------------------------------- |
| 市场条     | 均价+涨跌家数                  | 真实指数点位+涨跌家数+总成交额                             |
| 信号排名   | 仅强度排序                     | 加当日成交额对比（判断放量/缩量）                          |
| 空信号提示 | 固定文字"所有买入信号均被拦截" | 根据拦截原因给出具体建议（"7条被大盘择时挡住=今天不宜买"） |

| 项       | 当前                                 | 目标                               |

## 依赖关系

```
M1 (真实指数) ──→ M2 (信号首页市场条)
              ──→ M3 (市场监控指数+成交额)
              ──→ M5 (审查: 指数完整性)

M3 (板块数据) 需等待 report.py 积累数据，不依赖代码改动

M4, M5 可独立进行
```
