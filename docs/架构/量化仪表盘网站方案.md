### 页面 2：市场监控 🆕

**定位**：深入了解市场状态，判断当前环境适合什么策略。

**板块一：指数详情**

| 数据项 | 来源 | 展示方式 |
|------|------|------|
| CSI300 收盘价 | daily_kline AVG(close) | 大数字 + 涨跌幅 |
| 5/10/20/60 日涨跌幅 | 同上计算 | 四格数字 |
| 近 120 天走势 | daily_kline | CSS 柱状图或 ASCII chart |
| 成交量趋势 | daily_kline | 近 20 日均量 vs 60 日均量 |

**板块二：市场广度**

| 数据项 | 计算方式 | 含义 |
|------|------|------|
| 涨跌比 ADR | 当日上涨数/下跌数 | >1.5 过热，<0.5 恐慌 |
| MA20 以上占比 | close > MA20 的股票% | >70% 强势，<30% 弱势 |
| MA60 以上占比 | close > MA60 的股票% | 中期趋势确认 |
| 新高/新低 | 20日新高/新低股票数 | 趋势强度 |

**板块三：板块热度**

| 数据项 | 来源 | 展示方式 |
|------|------|------|
| 最强/最弱 5 板块 | sector_history | 排名表 + 涨跌幅 |
| 板块 5 日动量 | sector_history | 需要 ≥5 天数据 |
| 板块轮动提示 | 动量变化 | "资金从XX转向XX" |

**板块四：市场状态建议**

```
当前状态: 🟢 强势趋势
  → 趋势策略（均线、突破）优先级高
  → 均值回归策略降权
  → 止损可适当放宽（趋势中回调通常不深）

历史状态变化:
  2026-06: 🟢 强势
  2026-05: 🟡 震荡
  2026-04: 🔴 弱势
```

三个策略各一张卡片。从"这个策略是干什么的"到"最近为什么触发"，完整讲清楚。

**板块二：策略对比表**

| 维度 | 双均线 | 动量突破 | 均值回归 |

## 四、技术方案

### 方案A：每页独立 HTML（推荐）

```
dashboard/
├── index.html          ← 仪表盘首页
├── market.html         ← 市场监控
├── strategy.html       ← 策略分析
├── signals.html        ← 信号日志
├── factors.html        ← 因子引擎
├── stock.html          ← 股票详情（通过 ?code=000001 参数）
├── backtest.html       ← 回测报告
├── metrics.html        ← 指标讲解
└── health.html         ← 数据健康
```

**Python 生成器**：`scripts/generate_dashboard_data.py` 一次性生成全部 9 个 HTML 文件，共享同一个数据查询会话。

**导航**：顶部导航栏在生成时写入所有页面。

**优点**：零 JS、零服务器、双击即开、页面间可以链接跳转
**缺点**：数据更新需要重新生成

### 方案B：单页应用（SPA）

一个 HTML 文件，所有数据内嵌，点击导航切换显示/隐藏不同 section。

**优点**：切换页面瞬间完成、可以筛选排序
**缺点**：单文件较大、需要一些 JS

### 推荐：方案A
