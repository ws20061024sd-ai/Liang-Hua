> 2026-07-06 | 设计决策已定

---

## 设计决策

| 决策 | 选择 |
|------|------|
| 风格 | 博客一致：Tailwind CSS变量 + 明暗双主题 + system-ui字体 |
| 涨跌色 | 涨 #059669（accent-3） 跌 #dc2626（red-600） |
| K线图 | SVG 矢量图（120天OHLC蜡烛+MA叠加线），接入博客后升级 lightweight-charts |
| 信息密度 | 高密度有序：Grid多列、紧凑行高、分隔线区隔、重要信息左对齐 |
| 服务器 | cron每日生成 → blog public/quant/ → Next.js serve静态文件 |
| 数据嵌入 | Python直渲染HTML，零JS依赖，双击即开 |
