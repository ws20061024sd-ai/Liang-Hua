# 量化仪表盘网站方案 v3

> 2026-07-06 | 基于用户讨论重新设计

---

## 〇、设计原则

```
1. 打开网站，30秒内回答：今天该不该买、买哪只
2. 所有数据标注日期，过期=红色警告
3. 只显示对选股决策有直接帮助的信息
4. 不确定的数据（回测、单日板块）不展示或降级
5. 与用户无关的信号（非持仓卖出）不出现首页
6. ¥50 以上的股票从源头排除
```

---


**① 数据状态条**（一行）


```
CSI300 4120 · 🟢 强势 · 涨180/跌107 偏多 · 5日+2.3%
```


排名规则：强度×10 + 市场匹配(+0.3) + 交叉确认(+0.5)

```

```

### 不在首页出现的

## 六、数据流

```
cron 21:00  run.py           → 下载数据 + 生成信号 → daily_kline / signal_history
cron 21:05  report.py        → 缓存板块数据 → sector_history
cron 21:30  generate_dashboard_data.py → 读取所有表 → 生成全部 HTML
```

## 七、已解决问题清单

| 问题 | 解决 |
|------|------|
| 多因子推买不起的股票 | MAX_STOCK_PRICE=50，因子引擎源头过滤 |
| 本地回测不可信 | 首页不出现回测数字，策略页加免责 |
| 数据健康面板看不懂 | 删除，改数据状态条 |
| 市场广度指标太多 | 首页只留涨跌比 |
| 板块1天数据没价值 | <5天隐藏，攒够改5日累计分析 |
| 信号日志买卖混在一起 | 拆持仓/新机会/无关 |
| 信号推荐股票没有K线可看 | 新建股票详情页 |
