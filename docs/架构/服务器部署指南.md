# 服务器部署指南

> 适用：腾讯云 OpenCloudOS 8，`/root/Liang-Hua/`
> 更新：2026-07-05（随项目 v0.2.2 审查修复更新）

---

## 一、部署步骤

### 第一次部署

```bash
# SSH 到服务器
ssh root@<服务器IP>

# 克隆项目
git clone <仓库地址> /root/Liang-Hua
cd /root/Liang-Hua

# 一键部署
bash setup.sh

# 编辑 token 配置
vi config/settings_local.py
# 填入: DINGTALK_WEBHOOK = "https://oapi.dingtalk.com/robot/send?access_token=你的key"
# 填入: TUSHARE_TOKEN = "你的token"

# 配置定时任务
crontab -e
# 粘贴下面的 crontab 内容

# 首次下载全量数据
./venv/bin/python run.py --init
```

### 日常更新

```bash
ssh root@<服务器IP>
cd /root/Liang-Hua
git pull
# 如果 setup.sh 有新内容，重新运行
bash setup.sh
# 验证
./venv/bin/python run.py --no-update
```

## 二、Crontab 配置

```bash
# 量化交易系统定时任务
# 21:00 — 数据下载 + 策略运行 + 信号推送
0 21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python run.py >> logs/cron.log 2>&1

# 21:05 — 市场日报
5 21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python analysis/report.py >> logs/report.log 2>&1

# 21:10 — 🆕 健康检查（run.py 正常？无信号则钉钉告警）
10 21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python scripts/health_check.py >> logs/health.log 2>&1

# 21:15 — 🆕 数据库自动备份（保留 7 天）
15 21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python scripts/health_check.py --backup >> logs/health.log 2>&1
```

> ⚠️ 对比旧 crontab，新增了 21:10 健康检查和 21:15 数据库备份两条。务必加上。

## 三、需在服务器上创建的文件

### `config/settings_local.py`（必须手动创建）

此文件不会通过 git push 同步（已在 .gitignore），需要 SSH 到服务器手动创建：

```bash
cat > /root/Liang-Hua/config/settings_local.py << 'EOF'
# 服务器敏感配置
DINGTALK_WEBHOOK = "https://oapi.dingtalk.com/robot/send?access_token=你的实际token"
TUSHARE_TOKEN = "你的实际tushare token"
BARK_KEY = ""
EOF
```

## 四、新增目录结构

`git pull` 后服务器会自动获得这些新文件。确保以下目录存在：

```
/root/Liang-Hua/
├── config/
│   ├── settings.py
│   ├── settings_local.py    ← 🆕 手动创建，存 token
│   ├── logging_config.py    ← 🆕 日志配置
│   └── constants.py         ← 🆕 枚举常量
├── scripts/
│   └── health_check.py      ← 🆕 健康检查 + 备份
├── engine/
│   └── factors.py           ← 🆕 统一因子计算
├── notifier/
│   └── _common.py           ← 🆕 公共推送函数
├── data_fetcher/
│   ├── proxy_cleanup.py     ← 🆕 统一代理清理
│   └── trading_calendar.py  ← 🆕 交易日历
├── tests/                   ← 🆕 26 个单元测试
├── data/
│   └── backups/             ← 🆕 数据库备份（需创建）
├── logs/                    ← 已存在，新增 run.log / health.log
└── setup.sh                 ← 🆕 一键部署脚本
```

创建缺失目录：
```bash
mkdir -p /root/Liang-Hua/data/backups /root/Liang-Hua/logs
```

## 五、验证清单

部署后逐项确认：

```
□ git pull 成功（无冲突）
□ config/settings_local.py 存在且 token 已填入
□ python run.py --no-update 正常运行
□ python -m engine.factor_engine 正常运行
□ python scripts/health_check.py 正常运行
□ crontab -l 包含 4 条定时任务
□ Mac 本地 crontab 为空（crontab -l 返回 "no crontab"）
□ data/backups/ 目录存在
□ logs/ 目录存在
```

## 六、日志文件说明

| 文件 | 内容 | 轮转 |
|------|------|:--:|
| `logs/cron.log` | run.py 全部输出（stdout+stderr） | 手动 |
| `logs/report.log` | report.py 全部输出 | 手动 |
| `logs/run.log` | 🆕 run.py 结构化日志（时间戳+级别） | ✅ 自动 10MB×7 |
| `logs/health.log` | 🆕 健康检查 + 备份结果 | 手动 |

### 查看日志

```bash
# 查看今天的信号运行情况
tail -30 /root/Liang-Hua/logs/run.log

# 查看健康检查结果
cat /root/Liang-Hua/logs/health.log

# 查看 cron 错误
grep -i "error\|exception\|traceback" /root/Liang-Hua/logs/cron.log | tail -20
```

## 七、与旧版的关键差异

| 项目 | 旧版 | 新版 |
|------|------|------|
| Token 存放 | `config/settings.py`（Git 可见） | `config/settings_local.py`（gitignored） |
| Crontab | 2 条（信号+日报） | 4 条（信号+日报+健康检查+备份） |
| 日志 | 纯 print 重定向 | logging 模块（时间戳+级别+轮转） |
| 交易日判断 | `weekday() >= 5` | AKShare 交易日历（支持长假） |
| 数据备份 | 无 | 每日自动 + 保留 7 天 |
| 崩溃通知 | 无 | 钉钉自动告警 |
| 部署方式 | 手动逐项 | `bash setup.sh` 一键 |
