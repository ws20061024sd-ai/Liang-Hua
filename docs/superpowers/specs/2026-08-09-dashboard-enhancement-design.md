# 仪表盘增强设计：板块热力图 + K线悬停 tooltip

> 日期：2026-08-09 · 状态：已获用户认可 · 对应项目：量化交易仪表盘（web/generate.py）

## 背景与目标

用户优化量化仪表盘（`web/generate.py` 生成的纯静态 HTML，部署于 xolnxoln.cn/works/quant）。经讨论确定两个需求：

1. **板块热力图**——矩形色块图，红涨绿跌，色块大小 = 板块成分股数量
2. **K线悬停/点击 tooltip**——完整信息（日期、开高低收、涨跌幅、成交量），桌面悬停 + 手机点击均触发

明确不做：手机端整体适配（用户认为"还好，暂时不管"）、ECharts 等外部依赖（保持零 JS 依赖架构）。

## 技术决策

**方案 A：纯静态增强（已选定）**

| 项 | 决策 |
|----|------|
| 热力图 | generate.py 渲染时直接输出 CSS 色块，零 JS |
| K线 tooltip | 保留现有 SVG + 加 ~50 行内联 JS |
| 新依赖 | 无（不引入 ECharts） |
| 色块大小 | = 成分股数量（`up_count + down_count`，来自 sector_history 现有字段，不新增数据源） |

理由：仪表盘"零 JS 依赖"是刻意架构（COS 静态托管、加载快、部署简单）；"每天看一眼"的使用频率不需要图表库的重交互。

## 设计详情

### 1. 板块热力图（market.html）

**位置**：`page_market()` 板块分析区域——"5日累计涨幅排名"表格上方，两者互补（热力图看当日、表格看趋势）。

**数据**：`sector_history` 表当日数据（name, pct_change, up_count, down_count）。

**渲染**：

```
┌─────────────────────────────────────────────┐
│  🗺 板块热力图 · 2026-08-07                  │
│  ┌────┐ ┌───────┐ ┌──┐ ┌────────┐ ┌─────┐  │
│  │券商│ │半导体 │ │银行│ │白酒    │ │军工 │  │  ← 色块大小∝成分股数
│  │+2.1│ │+3.4   │ │+0.2│ │-1.2    │ │+0.8 │  │  ← 颜色=当日涨跌幅
│  └────┘ └───────┘ └──┘ └────────┘ └─────┘  │  （红涨绿跌，A股习惯）
│  ... (flex 自动换行)                         │
└─────────────────────────────────────────────┘
```

- **颜色**：涨跌幅映射——涨幅越大越红（深→浅），跌幅越大越绿，平盘灰。使用现有 CSS 变量 `--up`（红）`--down`（绿），暗色模式自动适配。幅度用预定义色阶（3 档）：|pct| < 0.5% 浅色（opacity 0.35）、0.5%–2% 中色（opacity 0.6）、> 2% 深色（opacity 1.0），底色为 `--up`/`--down` 变量
- **大小**：按成分股数比例，设上下限保护（避免"银行 vs 小行业"差距过大导致布局失衡）
- **悬停**：`title` 属性显示"板块名 · 涨跌幅% · N只成分股"（零 JS）
- **不做**：点击跳转板块个股列表（YAGNI）

### 2. K线悬停/点击 tooltip（所有 stock_XXX.html）

**改动**：

1. **SVG 加数据属性**：`_render_svg_kline()` 每根 K 线矩形加：
   ```
   data-date="2026-08-07" data-o="4588.2" data-h="4600.1"
   data-l="4560.3" data-c="4590.5" data-pct="+0.63" data-vol="2356万"
   ```
   （volume 格式化：万/亿）

2. **内联 JS tooltip**（~50 行，注入 `_page()` 公共模板）：
   - `mousemove` → 定位鼠标下方最近 K 线 → 显示浮层
   - `click` / `touchstart` → 同样触发（手机可用）
   - 浮层内容：
     ```
     2026-08-07  +0.63%
     开 4588.2   高 4600.1
     低 4560.3   收 4590.5
     成交量 2356万
     ```
   - 样式用现有 CSS 变量（`--bg-card-solid`、`--border`、`--text`），暗色模式自动适配
   - 移出图表区域 → 隐藏

3. **降级安全**：无 JS 环境下页面照常显示（SVG 结构不动，仅多 data 属性和 script）；JS 报错不影响页面其他部分

## 改动文件清单

**唯一改动文件**：`web/generate.py`

| 改动点 | 位置 |
|--------|------|
| 热力图生成函数 | 新增（`_sectors()` 附近），`page_market()` 调用 |
| 热力图 + tooltip CSS | 现有 CSS 设计系统内追加 |
| K线 SVG `data-*` 属性 | `_render_svg_kline()` |
| tooltip JS | `_page()` 公共模板注入 |

**不动的**：数据下载器、策略、信号、风控、其他页面结构——纯展示层改动，不影响数据链路。

## 验证

1. 本地 `PYTHONPATH=. python web/generate.py` → 检查 market.html 含热力图、stock 页含 tooltip JS
2. `python -m pytest tests/ -q` → 31 用例不受影响
3. git push → 服务器 git pull → 服务器跑 generate.py + coscmd 上传 → curl 线上页面验证
4. 浏览器人工验证：热力图颜色/大小、K线悬停 tooltip、暗色模式

## 风险

- 低。改动隔离在 generate.py 展示层；tooltip JS 失败只影响悬停提示，不影响页面
- 热力图无历史回看（YAGNI，后续需要再加）
