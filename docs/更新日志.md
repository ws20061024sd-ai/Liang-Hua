## [v0.3.1] - 2026-07-28

### 🚀 新增
- **成分股本地缓存**：`fetch_hs300_constituents()` 优先读 `stock_info` 表，99% 的运行不调 API
- **数据库自动迁移**：`scripts/ensure_schema.py`，启动时自动检测缺失列并 `ALTER TABLE ADD COLUMN`
- **ROE 集成到 run.py**：覆盖率不足时自动触发 `roe_downloader.py`（同花顺接口，300 只 ~154s）
- **Baostock 增量下载**：已有数据时仅下载最近 7 天增量（首次 90s，增量 ~5s）
- **服务器 cron 全线自动化**：5 条定时任务（21:00 信号 → 21:05 日报 → 21:10 健康检查 → 21:15 备份 → 21:20 仪表盘+COS 上传）
- **API 超时保护**：`signal.alarm(30)` 30 秒超时，防止网络不通时无限挂起

### 🔧 修复
- run.py 成分股 API 无超时导致服务器卡死 → 缓存 + 30s 超时
- 数据库 schema 漂移 → `ensure_schema` 零手工自动补列
- runner.py stop signals KeyError（`code` vs `stock_code` key 名不一致）
- COS 密钥在聊天中明文泄露 → 轮换密钥
- ROE 校验逻辑缺陷：查最新季度永远只有 2 只 → 改为查最近达标季度（Q1: 300 只）
- 东财备用源失败刷 319 行警告 → 静默处理，由上层重试逻辑统一管理

### ⚡ 优化
- 日线下载：去 `sleep(0.15)` + 批量 SQL（1 次 GROUP BY 替代 300 次单查），~160s → ~100s
- 东财警告降噪：备用源失败不再逐行打印

### 📄 文档
- **项目架构详解.md**（新建）——58 个 Py 文件 / 9,381 行 / 14 章节完整全貌
- 服务器部署指南更新——加仪表盘 cron + COS 上传章节
- 项目复盘与经验整理更新——问题 45-48 + 决策 24-27 + 模式 5.15-5.17
- 项目下一步计划更新——M1 完成状态
