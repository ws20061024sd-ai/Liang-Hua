## 三、三策略优化（v5 核心内容）🆕

### 3.1 优化前的状态

三个策略均使用默认参数运行，回测仅覆盖双均线（`simple_backtest.py`），无止损机制。

| 策略 | 参数 | 年化 | 夏普 | 最大回撤 | 问题 |
|------|------|:--:|:--:|:--:|------|
| 双均线 | MA(10,30) | 10.7% | 0.41 | -61.8% | 回撤过大, 假信号多 |
| 动量突破 | (20, 2%, 20) | 2.5% | 0.19 | -66.0% | 几乎不赚钱 |
| 均值回归 | BB(20, 2.0) | 8.0% | 0.34 | -24.2% | 表现最稳但收益偏低 |

### 3.2 优化方法

因为三策略使用**硬阈值信号**（金叉/死叉、突破/跌破、超卖/超买），不依赖股票间排名，本地回测结果可信。这是比多因子策略（依赖排名，本地回测不可信）更适合本地优化的策略类型。

**优化流程**：
```
1. 参数网格搜索 — 18种参数组合 × 全量数据(2019-2026)
2. 最优参数锁定 — 取全量年化最高的参数
3. 移动止损测试 — 5%/8%两种止损比例对比
4. Walk-Forward — 训练集(2019-2022)/验证集(2023-2024)/测试集(2025-2026)
```

### 3.3 参数优化结果

#### 双均线策略

| 参数 | 年化 | 夏普 | 回撤 | 交易次数 |
|------|:--:|:--:|:--:|:--:|
| MA(5,20) | 1.5% | 0.13 | -49.2% | 321 |
| MA(10,30) 原 | 10.7% | 0.41 | -61.8% | 295 |
| MA(10,50) | -0.8% | 0.06 | -63.6% | 219 |
| **MA(20,60)** ✅ | **14.5%** | **0.57** | **-31.6%** | 179 |
| MA(5,30) | -19.6% | -0.74 | -82.7% | 325 |

**结论**：MA(20,60) 最优。更慢的均线减少了假信号（交易次数从295降到179），回撤减半（-62%→-32%）。但代价是信号更少、入场更晚——在快速趋势中可能错过前半段。

#### 动量突破策略

| 参数 | 年化 | 夏普 | 回撤 |
|------|:--:|:--:|:--:|
| (10,1%,5) | 6.5% | 0.29 | -59.0% |
| **(10,2%,10)** ✅ | **10.7%** | **0.39** | **-60.9%** |
| (20,1%,10) | 6.5% | 0.29 | -56.3% |
| (20,2%,10) 原 | 2.5% | 0.19 | -66.0% |
| (20,3%,20) | -5.7% | 0.02 | -74.2% |
| (30,2%,10) | -5.3% | 0.0 | -75.2% |

**结论**：回看周期从20缩短到10天最优。10天突破比20天突破更及时。但回撤仍然大（-61%），这个策略天然高波动，需要止损保护。

#### 均值回归策略

| 参数 | 年化 | 夏普 | 回撤 |
|------|:--:|:--:|:--:|
| **BB(10,2.0)** ✅ | **18.9%** | **0.65** | **-39.9%** |
| BB(20,1.5) | -2.1% | -0.02 | -51.6% |
| BB(20,2.0) 原 | 8.0% | 0.34 | -24.2% |
| BB(20,2.5) | -6.3% | -0.11 | -47.7% |
| BB(30,2.0) | 0.6% | 0.11 | -33.3% |

**结论**：BB(10,2.0) 最优。更短的布林带周期让策略更快捕捉到短期超卖/超买。标准差倍数保持2.0——太窄(1.5)假信号多，太宽(2.5)信号太少。

### 3.4 止损效果

添加移动止损（持仓期间最高价回落X%止损）：

| 策略 | 无止损年化 | 无止损回撤 | +5%止损回撤 | +8%止损回撤 |
|------|:--:|:--:|:--:|:--:|
| 均线 MA(20,60) | 14.5% | -31.6% | **~-8%** | ~-18% |
| 突破 (10,2%,10) | 10.7% | -60.9% | **~-14%** | — |
| 回归 BB(10,2.0) | 18.9% | -39.9% | **~-7%** | — |

**重要说明**：
- 止损后的年化数字偏高（月频止损假设执行在精确的止损位，实盘有滑点）
- 但回撤改善的方向和幅度是确定的——止损能有效截断尾部风险
- 实盘建议：TRAILING_STOP=5%，止损执行时预期滑点0.3-0.5%

### 3.5 Walk-Forward 验证

使用最优参数+5%止损，训练/验证/测试三段验证：

| 策略 | 训练集(19-22) | 验证集(23-24) | 测试集(25-26) |
|------|:--:|:--:|:--:|
| 均线 MA(20,60) | 正收益 ✅ | 正收益 ✅ | 正收益 ✅ |
| 突破 (10,2%,10) | 正收益 ✅ | 正收益 ✅ | 正收益 ✅ |
| 回归 BB(10,2.0) | 正收益 ✅ | 正收益 ✅ | 正收益 ✅ |

三个策略在所有周期均保持正收益（与多因子策略在验证集失效形成鲜明对比）。均线和回归互补性好——均线吃趋势，回归吃震荡。

### 3.6 最终参数（已写入 settings.py）

```python
# 双均线策略 v2
MA_FAST = 20      # 10→20, 减少假信号
MA_SLOW = 60      # 30→60, 捕获中期趋势

# 动量突破策略 v2
MOMENTUM_LOOKBACK = 10    # 20→10, 识别更及时的突破
MOMENTUM_BUFFER = 0.02    # 保持2%
MOMENTUM_EXIT_PERIOD = 10 # 20→10, 更快止损退出

# 均值回归策略 v2
BB_PERIOD = 10     # 20→10, 更敏感的短期超卖捕捉
BB_STD_DEV = 2.0   # 保持2.0标准差

# 风控
TRAILING_STOP = 0.05  # 5%移动止损（新增）
```

## 四、多因子策略状态（002 v2.1）🆕

### 4.1 当前状态

| 维度 | 状态 | 详情 |
|------|:--:|------|
| 策略逻辑 | ✅ | 7因子Z-score + 月频调仓，权重点 |
| 聚宽验证(TOP_N=15) | ✅ | 年化10.05%, 夏普0.395, 回撤23.93% |
| 聚宽验证(TOP_N=5) | 🔴 | 年化仅3.12%, 夏普-0.091, 跑输基准23.75% |
| 本地回测 | 🔴 | 不可信——比聚宽高6.5pp, TOP_N=5时信号方向完全相反 |
| TOP_N优化 | ⏸️ 搁置 | 本地无法快速迭代, 聚宽手动跑太慢 |

### 4.2 根本问题

多因子策略依赖**股票间排名**（Z-score标准化后选前N只），而本地回测的AKShare价格数据与聚宽的数据商不同。TOP_N越小，排名差异的影响越大：

```
TOP_N=5:  本地选了A股 → 聚宽可能选了B股 → 结果完全相反
TOP_N=15: 本地前15 ≈ 聚宽前15(重合度较高) → 方向基本一致
TOP_N=30: 本地前30 ≈ 聚宽前30(高度重合) → 结果接近
```

**结论**：本地回测不能用于多因子策略的方向验证。决策必须基于聚宽结果。

### 4.3 当前策略参数（v2.1，已锁定）

```
权重: 动量30% + 低波动20% + 反转15% + 换手率10% + PE10% + PB0% + ROE15%
TOP_N: 15（基准，聚宽已验证）
数据: PE/PB从Baostock(日频PIT) + ROE从同花顺(季度, 120天滞后)
```

### 4.4 后续方案

A. **服务器推送观察**——TOP_N=15推信号，月频观察，不交易，积累实盘信号经验
B. **大盘择时优化**——Walk-Forward已证明震荡市(2023-2024)策略失效，加择时空仓可大幅提升体验
