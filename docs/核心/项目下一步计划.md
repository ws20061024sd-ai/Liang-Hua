```

     无持仓 → 不显示

  ④ 买入信号排名表（核心）
     列: # | 信号 | 代码 | 名称 | 策略 | 价格 | 强度 | 理由 | 操作
     排名规则: 强度×10 + 市场匹配(+0.3) + 交叉确认(+0.5)
     交叉确认标记 ⭐⭐
     价格 > ¥50 不出现（已在源头过滤）
     [查看详情 →] 链接到 stock_XXXXXX.html

  ⑤ 拦截统计（一行）
     📋 今日拦截76条：买不起50·跌停12·择时8·其他6

  ⑥ 底部链接
     [策略分析] [因子参考] [市场监控] [信号日志]

  不在首页出现:
    ✗ 回测数字  ✗ PE/PB覆盖率  ✗ DB大小
    ✗ ADR/MA占比  ✗ 非持仓卖出信号  ✗ 板块(数据不足)
```
