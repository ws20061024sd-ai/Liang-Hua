## 一、修复原则

```
原则1: 每一条数据都必须标注日期。无日期 = 不可信。
原则2: 所有收益率旁边必须有CSI300同期收益做基准。
原则3: 最重要信息放最前面——市场状态 → 今日信号 → 持仓风险。
原则4: 仪表盘的目的不是"展示数据"，是"帮助选股"。
原则5: 数据不新鲜 = 红色警告。不允许静默过期。
原则6: 任何有已知偏差的数据（如回测收益）必须标注免责声明。
```

## 二、Phase 1：数据可信度 🔴

### 1.1 每个面板加数据日期标注

**当前**：所有面板都没有日期。

**改为**：每个面板的标题栏右侧显示数据日期。格式：`数据: 07-03`。如果数据超过2天，日期变红。

```
改动: scripts/generate_dashboard_data.py
  - 所有 render 函数中每个 panel-hd 加 <span class="dim">数据: {date}</span>
  - 日期超过2天 → class="dn"
```

### 1.2 数据新鲜度大警告

首页顶部加醒目横幅：

```
如果日线超过2天未更新:
  ⚠️ 日线数据截止 07-03，已过期 3 天。最新市场状态无法判断。

如果 financial_data 超过7天未更新:
  ⚠️ PE/PB 数据截止 06-16，已过期 21 天。估值因子不可靠。

如果 signal_history 最新日期 ≠ 日线最新日期:
  ⚠️ 信号数据截止 06-12，策略已有 21 天未运行。
```

### 1.3 基准收益强制对比

所有出现收益率的地方，旁边必须标注 CSI300 同期收益。

```
当前:  年化 14.5%
改为:  年化 14.5%（同期CSI300: +8.2%）  ← 赚了6.3%超额
```

```
当前:  最大回撤 -31.6%
改为:  最大回撤 -31.6%（同期CSI300: -25.1%）  ← 比指数多跌6.5%
```

### 1.4 所有回测数字加免责声明

在策略卡片和回测报告中加显著声明：

```
⚠️ 回测收益 ≠ 实盘收益。以下因素导致回测数字偏高:
  · 本地数据源(AKShare)与实盘价格存在差异（约+3~6pp）
  · 止损模拟假设精确执行（实盘有滑点）
  · 未考虑最低佣金对小资金的影响
  → 保守估计: 实盘收益 ≈ 回测收益 × 0.6~0.8
```

### 1.5 重新下载 financial_data

当前 financial_data 停留在 6/16，差 21 天。执行：

```
python run.py  # 触发增量下载，financial_data 应更新到 7/3
```

### 3.2 信号拦截原因透明化

- 跌停拦截 X 条
- 停牌拦截 X 条
- ST 拦截 X 条
- 涨停拦截 X 条
- 大盘择时拦截 X 条

## 五、Phase 4：前端重设计 🟡

### 5.1 信息层级重构

```
首页从上到下:
  1. 数据新鲜度横幅（如果过期 → 红色警告，不可跳过）
  2. 综合推荐面板（最重要的选股建议）
  3. 市场状态四格（CSI300 + 涨跌幅 + 涨跌比）
  4. 今日信号摘要（买入/卖出/拦截统计）
  5. 策略表现对比（三策略卡片）
  6. 持仓风险（如果有持仓）
  7. 数据健康（运维信息，放最下面）
```

### 5.2 字体分层

```
等宽字体: 代码、数字、表格
系统字体: 说明文字、标题、标签
```

### 5.3 颜色规范

```
绿色(#0ecb81): 正面——上涨、盈利、通过
红色(#f6465d): 负面——下跌、亏损、拦截
蓝色(#4a9eff): 中性/信息——链接、强调、趋势策略
紫色(#a85cef): 反转策略
黄色(#f0b90b): 警告——数据过期、异常
灰色(#848e9c): 辅助文字
```

### 5.4 移动端适配

当前在手机上列全部塌缩。改为移动端保留核心信息（市场状态+综合推荐+今日信号），其他面板隐藏可展开。

## 八、验收标准

修复完成后，用户打开仪表盘应该能够：

```
□ 一眼看到数据是否新鲜（过期=红色警告）
□ 一眼看到综合选股建议（不需要自己拼凑）
□ 每看到一个收益率，旁边就有基准对比
□ 知道哪些信号被拦截、为什么被拦截
□ 知道每个面板的数据是哪一天的
□ 知道本地回测数据有偏差（免责声明）
□ 用手机也能看清核心信息
```
