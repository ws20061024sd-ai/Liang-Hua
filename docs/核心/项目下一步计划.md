## 最优先：服务器部署 + 博客集成

### 第一步：服务器部署

```bash
# 1. SSH 登录
ssh root@193.112.220.113

# 2. 拉取最新代码
cd /root/Liang-Hua && git pull

# 3. 验证
./venv/bin/python run.py --no-update
./venv/bin/python web/generate.py

# 4. 更新 crontab（加第5条）
crontab -e
# 追加: 20 21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python web/generate.py >> logs/dashboard.log 2>&1
```

### 第二步：COS 自动上传（仪表盘 → 博客域名）

在服务器上配置 coscmd，cron 里加一条上传：

```bash
pip install coscmd
coscmd config -a SECRET_ID -s SECRET_KEY -b xolnxoln-1431302682 -r ap-guangzhou
# crontab 第5条改为:
# 20 21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python web/generate.py >> logs/dashboard.log 2>&1 && coscmd upload -r web/output/ /quant/ --delete >> logs/dashboard.log 2>&1
```

### 第三步：博客程序页（需操作博客仓库）

| 文件                             | 操作                                   |
| -------------------------------- | -------------------------------------- |
| `src/app/apps/page.tsx`        | apps 数组追加量化仪表盘卡片            |
| `src/app/works/quant/page.tsx` | 新建，iframe 嵌入`/quant/index.html` |

效果：`xoln.me/apps` → 量化仪表盘卡片 → 点击进入 `xoln.me/works/quant` → 仪表盘首页
