## Layer 2：factor_engine.py

**2.1 源头价格过滤**

`compute_factor_scores()` 在计算因子之前，先查询所有股票最新收盘价，排除 > MAX_STOCK_PRICE 的。

```python
# 查询最新价格
price_map = {code: close} from daily_kline WHERE date = MAX(date)

# 过滤
if MAX_STOCK_PRICE > 0:
    codes = codes[codes['code'].isin({c for c, p in price_map.items() if p <= MAX_STOCK_PRICE})]
```

**效果**：中际旭创(¥1116)、新易盛(¥526) 等高价股从源头排除，不再出现在因子排名中。

**2.2 返回现价字段**

`compute_factor_scores()` 输出 DataFrame 加 `close` 列，仪表盘不再显示 `¥?`。
