## 六、长期不做的事

| 事项 | 原因 |
|------|------|
| 本地回测优化多因子 | 本地和聚宽数据源不同，排名策略无法本地迭代 |
| 聚宽手动跑 TOP_N 全量 | 太慢，等聚宽开放 API 再说 |
| 新数据源接入（除 ROE 外） | Baostock + AKShare + 同花顺 覆盖当前全部需求 |
| CI/CD 管道 | 单人项目不需要 |
| Parquet/DuckDB 存储 | SQLite 当前够用（125MB），查询 < 1 秒 |
| 实盘跟单 | 观察期至少 2 周后再评估 |
| React 重写仪表盘 | 当前纯 HTML + Python 渲染满足需求 |
