## 〇、设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 风格 | 博客一致（Tailwind + CSS变量 + 明暗双主题） | 用户要求 |
| K线图(独立HTML) | SVG 矢量迷你图 | 精细、无外部依赖、可缩放 |
| K线图(接入博客后) | lightweight-charts (TradingView) | 专业级、React可集成 |
| 信息密度 | 高密度有秩序 | 用户要求 |
| 服务器更新 | cron + Python生成 → 博客public/目录 | 全自动 |

**4.4 SVG K 线图实现**

```svg
<svg viewBox="0 0 600 200">
  <!-- 每根K线: rect(x, y, w, h) -->
  <!-- 阳线: fill="var(--up)"  阴线: fill="var(--down)" -->
  <!-- MA20: polyline, stroke="var(--accent)" -->
  <!-- MA60: polyline, stroke="var(--accent-2)" -->
</svg>
```

优点：矢量缩放不模糊、纯文本生成无依赖、文件小（~5KB/张）。

### Layer 6：服务器部署预案

**6.1 服务器 cron**

```bash
# 数据+信号
0  21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python run.py >> logs/cron.log 2>&1
# 市场日报（含板块数据缓存）
5  21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python analysis/report.py >> logs/report.log 2>&1
# 仪表盘数据刷新
30 21 * * 1-5 cd /root/Liang-Hua && ./venv/bin/python scripts/generate_dashboard_data.py >> logs/dashboard.log 2>&1
```

**6.2 接入博客（Next.js）**

```
方案: 静态文件 serve

服务器生成 → 同步到博客 public/quant/
  dashboard/index.html       → blog/public/quant/index.html
  dashboard/stock_*.html      → blog/public/quant/stock_*.html
  dashboard/strategy.html     → blog/public/quant/strategy.html
  ...

博客路由:
  /works/quant                → public/quant/index.html
  /works/quant/stock/000001   → public/quant/stock_000001.html

Next.js 配置:
  // next.config.js — 无需配置，public/ 下文件自动 serve

  // src/app/works/quant/page.tsx — 可选: iframe嵌入或直接重定向
```

**6.3 K线图升级路径**

```
Phase 1 (当前):  SVG 矢量图，嵌入独立 HTML
Phase 2 (接入后): lightweight-charts React 组件
  - npm install lightweight-charts
  - 数据从 public/quant/data.json 读取
  - 交互式缩放、十字光标、时间周期切换
```
