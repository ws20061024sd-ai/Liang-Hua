## 〇、用户的核心需求

```
打开网站 → 30秒内能回答:
  1. 三策略今天发出了什么买入信号？
```

## 二点五、实现方式

每只被选中的股票生成一个独立 HTML 文件：`stock_000001.html`。

```
dashboard/
├── index.html          ← 信号首页（新）
├── stock_000001.html   ← 平安银行
├── stock_600519.html   ← 贵州茅台
├── strategy.html       ← 策略分析
├── health.html         ← 数据健康
├── signals.html        ← 信号日志
├── market.html         ← 市场监控
└── factors.html        ← 因子引擎
```

从信号首页点击 `[查看K线图 →]` 跳转到 `stock_000001.html`。

## 四、不做的

| 事项 | 原因 |
|------|------|
| JS 图表库（Chart.js/ECharts） | 依赖 CDN，被墙就白屏。纯 CSS 柱状图够用 |
| 实时推送 | 静态 HTML 刷新即可 |
| 用户登录/权限 | 单人使用 |
| 移动端深度适配 | 桌面为主，手机能看就行 |
| 多因子推荐权重提升 | 用户已明确多因子是辅助角色 |
