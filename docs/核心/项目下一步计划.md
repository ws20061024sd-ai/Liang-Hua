# 仪表盘优化计划

> 2026-07-06 | 基于讨论逐项汇总

---

## 〇、已确认的问题与方案

| # | 问题 | 用户反馈 | 方案 |
|:--:|------|------|------|
| 1 | 多因子排名推买不起的股票 | "讲实话我根本买不起" | 因子引擎源头过滤 MAX_STOCK_PRICE=50 |
| 2 | 本地回测数字不可信 | "挺扯的，我不信" | 首页不出现回测数字，策略页加醒目免责 |
| 3 | 数据健康面板看不懂 | "根本没看懂是啥" | 删除，改成简洁数据状态条 |
| 4 | 市场广度指标太多 | "除了涨跌别的没看懂" | 首页只留涨跌比一句话，其余搬到市场页 |
| 5 | 板块只有1天数据没价值 | "1天数据能看出什么趋势" | 数据<5天隐藏，攒够改5日累计分析 |
| 6 | 信号日志买卖混在一起 | "卖的我根本没买" | 拆成持仓卖出+新机会，无关信号不显示 |
| 7 | 股价上限 | "五十就五十" | MAX_STOCK_PRICE = 50 |
| 8 | 多因子不是主力 | "回测数据不好" | 降级为辅助参考 |

## 二、不做的

| 事项 | 原因 |
|------|------|
| 回测数字出现在首页 | 用户不信任本地回测 |
| 数据健康面板（PE/PB覆盖率、DB大小） | 用户看不懂，没价值 |
| 板块面板（当前版本） | 数据仅1天，无分析价值 |
| 卖出信号（非持仓） | 用户没买，与你无关 |
| 因子引擎排名权重调高 | 用户说回测不好，保持辅助角色 |
