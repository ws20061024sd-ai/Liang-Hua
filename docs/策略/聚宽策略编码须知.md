## 2. get_price 正确用法

### 核心规则

```python
# ✅ 正确写法
df = get_price(
    stocks,                              # 股票列表
    start_date=context.previous_date - pd.Timedelta(days=500),
    end_date=context.previous_date,      # 动态日期！不要硬编码
    frequency='daily',
    fields=['close', 'volume'],          # 多字段
    fq='pre',                            # 前复权
    panel=False,                         # ← 必须！返回长格式 DataFrame
    # 不传 skip_paused！多股票时传了会报错
)

# ❌ 这几种都是错的
df = get_price(stocks, ..., panel=True)           # Panel 已废弃
df = get_price(stocks, ..., skip_paused=True)      # 多股票报错
df = get_price(stocks, ..., end_date='2026-06-01') # 硬编码日期——可能取不到未来数据
```

### 返回格式与处理

```python
# panel=False 返回长格式:
#   time       code          close    volume
#   2020-01-02 000001.XSHE   9.85     50000000
#   2020-01-02 000002.XSHE   15.32    30000000
#   2020-01-03 000001.XSHE   9.90     45000000
#   ...

# 转宽表（因子计算需要宽表）:
close_wide = df.pivot(index='time', columns='code', values='close')
# → index=date, columns=stocks, values=close

vol_wide = df.pivot(index='time', columns='code', values='volume')
# → index=date, columns=stocks, values=volume

# 切片最近 N 天:
close_recent = close_wide.iloc[-260:]
```

### attribute_history 对比

```python
# attribute_history: 只能单只股票，返回 Series
hist = attribute_history('000300.XSHG', 90, '1d', ['close'])
# → index=date, columns=['close']

# 多只股票必须用 get_price (panel=False)
```

## 3. get_fundamentals 正确用法

### 核心规则

```python
# ✅ 正确：用 date 参数，取最近财报
q = query(
    valuation.code,
    valuation.pe_ratio,
    valuation.pb_ratio,
    indicator.roe,
).filter(valuation.code.in_(stocks))

fin_df = get_fundamentals(q, date=context.previous_date)
# date 参数: datetime 对象（非字符串！）

# ⚠️ 注意：date 取的是最近财报，可能跨季度。
# 如果同一天有Q4+Q1两份季报，date 只会返回Q1（最新的）。
# 对月频策略影响可接受。

# ❌ 避免：statDate 容易引入未来数据
# get_fundamentals(q, statDate='2023q4')  ← 需要手动过滤 pubDate

# ✅ 防御：开启未来数据保护
set_option("avoid_future_data", True)
```

### 返回值

```python
# get_fundamentals 返回 DataFrame:
#   code          pe_ratio  pb_ratio  roe
#   000001.XSHE   5.2       0.8       12.5
#   000002.XSHE   12.1      1.5       8.3

# 转 dict 方便查找:
fin_map = {}
for _, row in fin_df.iterrows():
    fin_map[row['code']] = {
        'pe': row['pe_ratio'] if pd.notna(row['pe_ratio']) else None,
        'pb': row['pb_ratio'] if pd.notna(row['pb_ratio']) else None,
        'roe': row['roe'] if pd.notna(row['roe']) else None,
    }
```

## 4. 其他 API 注意事项

### get_current_data

```python
# ✅ 函数调用
cur = get_current_data()[stock]

# ❌ 全局变量（旧版API）
cur = current_data[stock]  # NameError in newer versions

# ✅ 必须检查
if cur is None or cur.last_price is None or cur.last_price <= 0:
    continue  # 停牌或数据异常
```

### order_target_value

```python
# ✅ 按金额调仓
order_target_value(stock, target_value)  # 买/调到目标金额
order_target_value(stock, 0)              # 清仓

# ⚠️ 不用 order_target (按股数)，小资金可能买不起1手
```

### run_monthly vs run_daily

```python
run_monthly(fn, 1, time='open')    # 月频，月初开盘
run_daily(fn, time='14:50')        # 日频，收盘前10分钟
# 'open' = 开盘成交，'close' = 收盘后（次日开盘成交）
```

## 5. 回测陷阱清单

| # | 陷阱 | 后果 | 修复 |
|:--:|------|------|------|
| 1 | get_price 硬编码 end_date | 回测中取不到未来数据 | 用 `context.previous_date` |
| 2 | skip_paused=True + 多股票 | ParamsError 崩溃 | 不传 skip_paused |
| 3 | 忘加 panel=False | Panel 废弃，数据取不到 | 加 `panel=False` |
| 4 | 列名格式不匹配 | 交集为0，空仓运行 | 先跑环境确认 |
| 5 | get_fundamentals 用 statDate | 未来数据/报错 | 用 `date=` 参数 |
| 6 | 盘中用 attribute_history 取日线 | 包含当日未完成K线 | 收盘后运行或用分钟线 |
| 7 | 不检查 cur.last_price | 停牌/退市股票报错 | 加 None 检查 |
| 8 | get_price 返回类型假设 | 当宽表用.loc[]报错 | 先确认格式再 pivot |
| 9 | 手续费/滑点没设 | 收益虚高 | set_order_cost + set_slippage |
| 10 | 复权方式错误 | 长期收益偏差 | 统一 fq='pre'（前复权） |

## 6. 策略开发标准流程

> 严格遵守——本项目聚宽代码改了 8 次的血泪教训。

```
第1步：环境确认（5分钟）
  → 跑 §1 的 check_env() 确认数据格式
  → 记录 columns 格式、code 格式、是否 MultiIndex

第2步：单月测试（5分钟）
  → 选一个日期（如 2020-06-01）
  → 手写 10 行代码验证：取数 → pivot → 算一个因子 → 看一只股票的值得分
  → 确认得分不为 0

第3步：1年回测（30秒）
  → 回测区间 2020-01-01 ~ 2020-12-31
  → 确认: 收益 ≠ 0%、日志无 ERROR、每月有交易

第4步：完整回测（1-3分钟）
  → 回测区间 2019-01-01 ~ 2026-06-01
  → 检查：年化收益合理(-20%~+30%)、最大回撤合理(10%~50%)、
          夏普合理(-1~2)、交易次数>调仓期数×持仓数/2
```

def select_top_stocks(scores_df, n, context):
    selected = []
    for _, row in scores_df.iterrows():
        stock = row['code']
        cur = get_current_data()[stock]
        if cur is None or cur.last_price is None or cur.last_price <= 0:
            continue
        # 涨停过滤
        if cur.high_limit and cur.last_price >= cur.high_limit * 0.995:
            continue
        selected.append(stock)
        if len(selected) >= n:
            break
    return selected


def execute_rebalance(stocks, context):
    total_value = context.portfolio.total_value
    n = len(stocks)
    if n == 0:
        return
    target_value = min(total_value * 0.10, total_value / n)
    for stock in list(context.portfolio.positions.keys()):
        if stock not in stocks:
            order_target_value(stock, 0)
    for stock in stocks:
        order_target_value(stock, target_value)
