# 002 多因子策略优化方案 v3

> 基于 Step 1 诊断 + Step 2 调研（MSCI 2025 A股因子报告、长江证券研报）
> 优化目标：夏普 0.38 → 0.50+，保持年化 10%+

---

## 一、调研核心发现

| 发现 | 来源 | 对002的影响 |
|------|------|------------|
| A股低波+价值因子持续领跑（优于动量） | MSCI 2025 中国A股因子报告 | 动量25%过高 |
| A股短期(1月内)是反转不是动量 | A股散户占比60-70% | 反转因子15%合理 |
| 价值因子中 E/P、CF/P 优于 B/M | 长江证券研报(2024) | PE因子方向正确 |
| A股规模因子年化-5.88% | MSCI 2011-2025数据 | 不需要加规模因子 |
| 不做行业中性化 → 风格切换时回撤大 | 知乎量化综述(2026) | 待v5实现 |
| 动态权重(牛市加动量，熊市加低波)提升IR 8倍 | 普林斯顿 SJM模型(2025) | v4实现 |

## 二、当前 002 问题诊断

```
问题1: 动量 25% 最高 → A股动量波动大 → 夏普被拖累
问题2: 低波动仅 15% → 明明是A股最强因子 → 严重低估
问题3: 价值(PE+PB)仅 20% → 防御力不足
问题4: ROE 15% 但聚宽数据可用性未验证 → 可能虚占权重
```

## 三、优化方案

### v3：纯权重优化（本次实现）

```
因子          当前权重    优化后     变化     理由
──────────────────────────────────────────────────
动量          25%   →   15%       -10%    A股动量波动大
低波动        15%   →   30%       +15%    A股最强因子(MSCI验证)
反转          15%   →   10%        -5%    短期噪音多
换手率        10%   →    5%        -5%    辅助因子
PE            10%   →   15%        +5%    价值防御
PB            10%   →   15%        +5%    价值防御
ROE           15%   →   10%        -5%    数据可用性待验证
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
风险端(低波+PE+PB)  35% → 60%      +25%    大幅增强防御
收益端(动量+反转)    40% → 25%      -15%    降低波动
```

### v4：大盘择时动态权重（下次）

利用本地 `market_timing.py` 的四档市场状态，动态调节：

```
🟢 强势 → 动量+5%,  低波-5%
🟡 震荡 → 反转+5%,  动量-5%
🟠 弱势 → PE/PB+5%, 动量-5%
```

### v5：行业中性化（后续）

防止动量因子把持仓集中到单一行业。

## 四、验证计划

```
第1步：聚宽回测 v3（只改权重，其他不变）
  回测区间：2019-01-01 ~ 2026-06-01
  预期：夏普 > 0.45, 最大回撤 < 22%, 年化 ≥ 10%

第2步：如果夏普达标 → 跑分年分析
第3步：对比 v2 vs v3 各年表现
```

## 五、预期改善（基于调研数据）

```
              002 v2(当前)    002 v3(预期)
夏普           0.379         >0.45
最大回撤       23.95%        <21%
年化收益       10.4%         ~10%
盈亏比         1.48          >1.5
2022年表现     -8.8%         >-6%（防御增强）

理由：低波动+价值从35%→50%，动量从25%→15%
      → 2022年熊市中防御力增强 → 回撤减小
      → 2019-2020牛市中收益略降 → 波动率显著降 → 夏普升
```
