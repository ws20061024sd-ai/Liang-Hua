### 关键观察

**1. 近三年非常稳定（2023-2025）**

```
连续三年正收益：+6.6%, +11.0%, +11.2%
平均年化：+9.6%
这三年没有一年亏损。
```

**2. 熊市防御有效**

2022 年沪深 300 跌 -21.6%，策略只亏 -8.8%。低波动和估值因子在市场恐慌时提供了保护。

**3. 牛市中跑不赢指数**

2019 年沪深 300 涨 36%，策略涨 25%。多因子天然偏保守——错过了一些暴涨机会，但也躲过了之后的暴跌。

## 六、夏普比率为什么低？

### 不是因为不赚钱——是因为 2019-2020 太赚钱了

```
夏普 = (年化收益 - 无风险利率) / 年化波动率

年化收益 10.4%、无风险利率 2%、波动率 16.9%
夏普 = (10.4 - 2) / 16.9 = 0.50

但实际报告显示 0.379，说明波动率可能更高（~22%），
原因：2019(+25%)和2020(+40%)的极端收益把波动率拉高了。
```

### 分时段夏普

```
时段          年化    近似波动    近似夏普
2019-2020    +32%      ~25%       1.20   ← 极高
2021-2022     -6%      ~18%      -0.44   ← 亏钱
2023-2025    +10%      ~14%       0.57   ← 正常偏优
```

近三年夏普 ~0.57——比总体 0.38 好看得多，也更有参考意义（因为它反映的是当前的策略质量，而不是 2019 年那种不会再来的大牛市）。

## 八、实盘可行性评估

### ✅ 有利因素

- 近三年连续正收益，策略当前有效
- 月频调仓，不需要盯盘
- 盈亏比 1.48，赚多亏少
- 熊市有防御（2022 仅 -8.8%）
- Beta 0.67，自带降波动

### ⚠️ 风险因素

- 最大回撤 -24%，需要心理承受力
- 夏普 0.38 偏低，风险调整后收益不突出
- 动量因子主导——在趋势市中表现好，震荡市中可能跑输
- 2026 年至今仅 +0.9%，需要观察

### 🟡 建议

## 九、后续优化方向

| 优先级 | 方向 | 预期效果 |
|:--:|------|------|
| 1 | 降动量权重(25%→15%)，提低波动(15%→25%) | 降波动，提升夏普 |

| 4 | 加入行业中性化 | 防止单一行业过度集中 |
